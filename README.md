# The picture that tastes of one ingredient

One perfect ripe strawberry — glossy, fresh, beaded with water, its green
calyx still on top — shot as a warm, mouth-watering hero photograph against
a soft cream background. A single ingredient, front and centre, so one look
is enough to taste it.

## How it works

`main.py` (Python 3.13, standard library only) copies the committed
`image.jpg` (1024×1024) to `/output/entry.png`. It runs in a sandbox with
no network access.
