# The picture that tastes of one ingredient

One perfect strawberry, photographed as if you could taste it: glossy red,
cool water droplets, fresh green leaves, warm light, nothing else in the
frame. A single ingredient, doing all the talking.

## Entry

- `image.jpg` — the entry picture (1024 × 1024 JPEG): one ripe strawberry,
  hero shot, centred on a neutral cream background.
- `main.py` — copies `image.jpg` unchanged to `/output/entry.png`,
  verifying it is a real JPEG within the 1,048,576-byte limit.
